This guide walks through creating a transcription from a file on your machine.
You get an upload URL and a short-lived token, send the file, then start a
transcription job and follow it until the transcript is ready. If your file is
already reachable over https, [transcribe from a URL](/transcribe-url) instead.

## Before you start

Mint an API key (see [Authentication](/authentication)) and export it:

```bash
export VOOK_API_KEY=vk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

The Python examples use the `requests` package (`pip install requests`).

## The flow at a glance

| Step | Call | What you get |
| --- | --- | --- |
| 1 | `POST /api/v1/uploads/init` | An `upload_url` and an `upload_token`. |
| 2 | `POST {upload_url}` | The file bytes are stored. |
| 3 | `POST /api/v1/transcription-jobs` | A job `id` to follow. |

Then poll the job, or receive a [webhook](/webhooks), and read its transcript.

## 1. Get an upload URL and token

Request where to send the file and a short-lived `upload_token`. You send this
token with the file in the next step and again when you create the job.

<CodeGroup>

```bash curl
curl -X POST "https://www.api.vook.ai/api/v1/uploads/init" \
  -H "Authorization: Bearer $VOOK_API_KEY"
```

```python Python
import os, requests

BASE = "https://www.api.vook.ai/api/v1"
headers = {"Authorization": f"Bearer {os.environ['VOOK_API_KEY']}"}

resp = requests.post(f"{BASE}/uploads/init", headers=headers)
resp.raise_for_status()
init = resp.json()
upload_url = init["upload_url"]
upload_token = init["upload_token"]
```

</CodeGroup>

```json
{
  "upload_url": "https://ingress.vook.ai/upload",
  "upload_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expires_at": "2024-01-15T10:30:00.000Z"
}
```

| Field | Description |
| --- | --- |
| `upload_url` | Absolute URL to send the file to in step 2. Use it as returned. |
| `upload_token` | Token scoped to this upload. Used in steps 2 and 3. |
| `expires_at` | When the token expires. Start the upload before this time; an upload already in flight completes normally. |

## 2. Upload the file

Send the file to `upload_url` as `multipart/form-data` in a single request.
Authenticate this request with the **`upload_token`** from step 1, not your API
key.

<CodeGroup>

```bash curl
curl -X POST "$UPLOAD_URL" \
  -H "Authorization: Bearer $UPLOAD_TOKEN" \
  -F "chunk=@meeting.mp3"
```

```python Python
upload_headers = {"Authorization": f"Bearer {upload_token}"}

with open("meeting.mp3", "rb") as f:
    resp = requests.post(
        upload_url,
        headers=upload_headers,
        files={"chunk": f},
    )
resp.raise_for_status()
```

</CodeGroup>

The fields are:

| Field | Where | Description |
| --- | --- | --- |
| `chunk` | form file | The raw file bytes. |
| `Authorization` | header | `Bearer {upload_token}`. |

A `2xx` status means the file is stored. Continue to step 3.

## 3. Create the transcription job

Start the transcription. Pass the `upload_token` and the file details. The
response gives you a job `id` and its `status`.

<CodeGroup>

```bash curl
curl -X POST "https://www.api.vook.ai/api/v1/transcription-jobs" \
  -H "Authorization: Bearer $VOOK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "upload_token": "'"$UPLOAD_TOKEN"'",
    "file_name": "meeting.mp3",
    "language": "en",
    "diarize": false,
    "name": "Team weekly sync"
  }'
```

```python Python
resp = requests.post(
    f"{BASE}/transcription-jobs",
    headers=headers,
    json={
        "upload_token": upload_token,
        "file_name": "meeting.mp3",
        "language": "en",
        "diarize": False,
        "name": "Team weekly sync",
    },
)
resp.raise_for_status()
job_id = resp.json()["id"]
```

</CodeGroup>

```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "status": "queued"
}
```

The request body fields are:

| Field | Required | Description |
| --- | --- | --- |
| `upload_token` | yes | The token from step 1. |
| `file_name` | yes | The original file name. |
| `language` | yes | Spoken language code, for example `en`. |
| `diarize` | yes | Set `true` to separate speakers. |
| `name` | no | Display name for the resulting transcription. |
| `callback_url` | no | Endpoint to notify when the job finishes. See [Webhooks](/webhooks). |

If your API credit balance needs a top-up, the request returns `402` with the
error code `insufficient_api_credits`. Top up, then send the request again.

## 4. Poll the job

Poll the job by `id` until its `status` is `completed` or `failed`. To be
notified instead, pass a `callback_url` and see [Webhooks](/webhooks).

<CodeGroup>

```bash curl
curl "https://www.api.vook.ai/api/v1/transcription-jobs/$JOB_ID" \
  -H "Authorization: Bearer $VOOK_API_KEY"
```

```python Python
import time

while True:
    resp = requests.get(f"{BASE}/transcription-jobs/{job_id}", headers=headers)
    resp.raise_for_status()
    job = resp.json()
    if job["status"] in ("completed", "failed"):
        break
    time.sleep(5)
```

</CodeGroup>

```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "status": "completed",
  "name": "Team weekly sync",
  "language": "en",
  "diarize": false,
  "transcription_id": "123e4567-e89b-12d3-a456-426614174000",
  "callback_url": null,
  "error_code": null,
  "created_at": "2024-01-15T10:30:00.000Z",
  "updated_at": "2024-01-15T10:30:00.000Z"
}
```

The `status` field reflects where the job is in its lifecycle:

| Status | Meaning |
| --- | --- |
| `queued` | Accepted, waiting to be processed. |
| `processing` | The job is running. `transcription_id` is set from this point. |
| `completed` | Finished; the transcript is ready. |
| `failed` | The job did not produce a transcript. `error_code` carries a short code describing the cause. |

`transcription_id` is the transcription this job produced. It is `null` until
the job reaches `processing`.

## 5. Read the result

Once the job is `completed`, read its transcript straight from the job:

<CodeGroup>

```bash curl
curl "https://www.api.vook.ai/api/v1/transcription-jobs/$JOB_ID/transcript" \
  -H "Authorization: Bearer $VOOK_API_KEY"
```

```python Python
resp = requests.get(
    f"{BASE}/transcription-jobs/{job_id}/transcript", headers=headers
)
resp.raise_for_status()
print(resp.json()["plain_text"])
```

</CodeGroup>

The job also has an export endpoint,
`GET /api/v1/transcription-jobs/{id}/export`, which takes the same query
parameters as the transcription export. Both job endpoints return `409` with
`job_not_completed` while the job is still running, or `job_failed` if it ended
without a transcript.

The job's `transcription_id` is also a regular transcription. Use it with the
endpoints from [Retrieve and export](/retrieve-export) to read its metadata or
list it alongside your other transcriptions.

## Delete the result

To delete the transcription a job produced, call
`DELETE /api/v1/transcription-jobs/{id}`. It returns `204` when the
transcription is deleted, or when the job has none to delete. A job that is
still running returns `409`; wait for it to finish, then retry.

```bash
curl -X DELETE "https://www.api.vook.ai/api/v1/transcription-jobs/$JOB_ID" \
  -H "Authorization: Bearer $VOOK_API_KEY"
```
