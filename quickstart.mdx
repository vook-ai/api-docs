---

The Vook API turns your audio and video into transcripts and gives you the
results back as structured text or ready-to-share files. You can run the whole
flow with an API key alone.

<Tip>
  To help you try the API, accounts without a subscription get one free
  transcript per day. It counts only when a transcript is delivered.
</Tip>

## The path

There are two stages: send a file for transcription, then read the result.

<Steps>
  <Step title="Authenticate">
    Mint an API key (see [Authentication](/authentication)) and send it as a
    Bearer token on every request:

    ```bash
    export VOOK_API_KEY=vk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    ```
  </Step>
  <Step title="Transcribe">
    Upload a file or pass a direct link to one, then start a transcription job.
    Full walkthroughs in [Transcribe from a file](/upload) and
    [Transcribe from a URL](/transcribe-url). Poll the job, or receive a
    [webhook](/webhooks) when the transcript is ready.
  </Step>
  <Step title="Retrieve and export">
    List your transcriptions, check status, read the transcript text, download
    an export, and delete what you no longer need. Full walkthrough in
    [Retrieve and export](/retrieve-export).
  </Step>
</Steps>
